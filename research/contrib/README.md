# Contributor Research Lane

This directory is the public intake surface for Wingless experiments run outside the official research runners/loop.

Start with [../../CONTRIBUTING_RESEARCH.md](../../CONTRIBUTING_RESEARCH.md) and copy `experiment-template.json` into:

`research/contrib/<your-handle>/<experiment-id>/prereg.json`

The preregistration commit must exist before the primary result for the work to qualify as confirmatory evidence.

After the run, add `result.json`, `provenance.json`, a reproduction README, and only the bounded code/artifacts required for the experiment.

External submissions are evidence only. They have no promotion, accepted-state, scheduler, evaluator, or production authority.
