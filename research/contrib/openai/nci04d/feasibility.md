# NCI-04D / Wingless — dynamics-conditioned entity identity
**Status:** source-grounded theoretical feasibility, **not a successful experiment**, not native acceptance.  
**Source base:** `a5db1727113731988bfccad6ae30a0b8b4d6f9d6` (T45-O native candidate, not protected main).  
**Scientific first-use:** **0**. Existing unsuccessful NCI-02/03/04/04C negative evidence remains unchanged.

## The distinct principle

Form internal entities from **counterfactual distinguishability under controlled experience** instead of nearest-neighbor similarity of sensory features. Two observations belong to the same persistent entity hypothesis only if their *learned distributions of future consequences under a set of available actions* remain compatible after nuisance transforms. Assign no human entity IDs, fixed identity slots, graph edges, supplied path operators, or terminal causal answers.

This is motivated by predictive-state representations (Singh et al., ICML 2003; Kulesza et al., AAAI 2015) but does **not** assert that the proposed mechanism is novel or works. Its substantive difference from Wingless's failed prototypes is using **action-conditional future-outcome discriminability** as the representation objective, not a source-visible feature threshold or post-hoc signed-path evaluation.

- The native experience event should contain `(observation_before, executed_primitive_action, observation_after, measured_consequence, continuity_metadata)`; continuity metadata may denote only uninterrupted acquisition order/time, not an identity label.
- **Learned state:** a fixed-budget set of online-born predictive hypotheses `h`, each with learned embedding, conditional response predictor, uncertainty, and duration/last-update statistics; create/merge/retire according to train-calibrated *difference of predictive consequences plus memory cost*, not closeness of raw input vectors. The budget limits total bytes, not predetermined entity-to-slot assignment.
- **Action selection:** use only actions allowed by the source-free simulator. If safe controlled probes are unavailable, **do not call an observational association causal**. No live robot, broker, or trading action is authorized.
- **Causal relationship:** estimate effects of controlled action `do(a)` on future observable consequences, conditioning on retained state. A sequence-level prediction is generated by repeatedly applying the native transition model, *without hardcoded sign product, graph traversal or external symbolic reasoner*. Any actual causal claim requires randomized/independently controlled action assignment or equivalent justified assumptions.
- **Memory:** transfer online-learned hypotheses from context A to B to later A without resetting weights, swapping sensor coordinates, or injecting task ID. Query/read must not mutate learning state. Unknown/ambiguous matches must support calibrated abstention.

## Feasibility and impossibility boundary

**Necessary observational condition:** if entities E₁ and E₂ have identical response distributions for **every admissible action history**, they cannot be reliably distinguished from this interface; any method claiming otherwise is exploiting identity leakage. If there exists an action-conditioned event whose outcome-probability gap is `Δ > 0`, then repeated independent bounded probes can in principle distinguish the hypotheses with enough experience. Conservatively, a union-bound/Hoeffding-style sufficient-sample scale is `O(log(K/α)/Δ²)` per comparison for K probes and allowable confusion α; temporal correlation and model misspecification can require more. This is a **separability argument**, not proof of learning capability.

**Current native blocker:** `cognition/continual.go` takes two binary inputs `action` and `prior` and a binary `outcome`; `features` returns only four fixed values `(1,a,p,a·p)`. It receives no raw entity observation, spatiotemporal continuity, or action-conditioned outcome trajectory; therefore the new representation **cannot be qualified against this interface without a bounded additive input seam**. `cmd/wingless/cognition.go` must retain original operations unchanged. Proposed opt-in interface is necessary, not by itself cognitive progress.

**Bounded compute:** for K active hypotheses, A action classes and d-dimensional fixed predictor, score/query budget `O(K A d)`; hard caps on K, raw history, parameter bytes, update arithmetic, and probes; no retained per-episode graph. A fast, high-performing trained GRU/relational model **receiving identical history and interventions** must be compared at equal or lower *total* training and inference cost. A strong symbolic system with valid action histories provides an upper-bound reference and a cheat/leakage detector.

## One feasibility decision *before* scientific first-use

1. Prove a source-free interface contract with **two aliased sensory objects whose admissible controlled outcomes differ**, and a complementary **indistinguishable-pair negative control**. An identity prediction on the latter is a hard false positive. **Do not** give the learner object IDs, context tags, coordinate-consistent slots, or an action oracle.
2. Demonstrate that the mechanism can learn to distinguish the action-conditioned pair **from prior observations alone**, retain the hypothesis across A→B→A and nuisance/permutation shifts, and predict consequences of an unfamiliar valid action sequence **from its learned dynamics**. Do not re-tune after reading development negatives.
3. Compare to fully trained, equally informed GRU/relational predictive-memory models, an online Bayesian/finite-state baseline and exact symbolic bounds. Run memory-removed, probe-removed, action-shuffled and time-order-shuffled ablations; report **all** hard false positives, accuracy/calibration, CPU time, peak RSS, permanent bytes, parameter count and total train cost.
4. **Go** only if learned separability transfers to genuinely unfamiliar independently born structures, query-blind retention is causal to the gain, zero hard false positives, and matched strong controls are beaten without CPU/memory regression. Otherwise preserve `NEGATIVE` or `INVALID`, stop the mechanism. The later scientific experiment requires separately sealed first-use authority; this design never consumes it.

## Why this is not another benchmark tune

The hypothesis targets an **observability/identifiability bottleneck** absent from previous predictive prototype comparisons. The decisive negative case tests impossibility, not threshold optimization. The work product for this gate is a reviewable native source contract, costed learning rule and the above falsifiers—not a claim of transfer merely from a new score.
