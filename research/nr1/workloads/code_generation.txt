Write a Go 1.25 package named boundedcache that implements a concurrency-safe fixed-capacity LRU cache for string keys and []byte values. Requirements: Get returns a defensive copy; Put replaces existing values without increasing size; capacity must be positive; eviction is deterministic; no background goroutines; no external dependencies. Include the package implementation and table-driven tests covering replacement, eviction order, defensive copies, and concurrent readers/writers.
