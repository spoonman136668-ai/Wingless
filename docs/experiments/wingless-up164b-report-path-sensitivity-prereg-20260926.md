## Question

UP-163B showed that the same trailing REPORT cleanup block can preserve, reverse, or create the final STORE↔OBSERVE order preference depending on the subject-specific path state. Which REPORT step creates those changes, and how does its update geometry differ across the two fixed pre-REPORT states?

## Frozen states

For each accepted subject:
- reconstruct the exact UP-160B post-interference gate;
- path A applies STORE then OBSERVE cleanup blocks;
- path B applies OBSERVE then STORE cleanup blocks;
- stop before the two REPORT cleanup examples.

Both paths use identical cleanup items and differ only by STORE/OBSERVE order.

## Frozen REPORT steps

Apply old-rehearsal REPORT indices 13 then 14 one at a time to each path state.

At each REPORT step record:
- old retention before and after;
- marginal old-retention change;
- one-step update norm;
- cosine of the one-step update with the frozen old-reference vector.

At matched states record:
- path A minus path B retention before REPORT;
- after REPORT item 13;
- after REPORT item 14;
- A/B gate distance at those same three states.

## Interpretation

The exact six-subject step table is the result. A sign flip after item 13 or 14 identifies the specific REPORT update at which path-dependent nonlinearity changes the winner. Similar retention effects despite different geometry would falsify a simple geometric projection explanation.
