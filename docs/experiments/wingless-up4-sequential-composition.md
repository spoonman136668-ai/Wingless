# Wingless UP-4: learned sequential memory/composition

Status: research branch only; not activated, promoted, or connected to ckb-plane.

Parent research qualification: UP-3 Windows qualification sealed at `d5f63c863af4cf85a813bc3d45cb8bccd6b89e2b`.

## Question

Can a learned unitary state-transition system acquire local operations from one-step supervision and then compose those operations correctly over unseen, order-sensitive sequences up to 128 events?

This is the first Wingless-UP experiment aimed at sequential state evolution rather than static routing or transport.

## State machine

The latent memory has four basis states.

Three event types act on adjacent state pairs:

- A acts on states 0 and 1;
- B acts on states 1 and 2;
- C acts on states 2 and 3.

The target semantics are discrete adjacent swaps. Because the operations overlap, composition is order-sensitive. Starting from state 0:

- A then B ends in state 2;
- B then A ends in state 1.

## Training boundary

Training contains only the 12 possible one-step examples:

- four starting states;
- three event types;
- one event per example.

No multi-event sequence appears in training.

Each model therefore receives enough information to learn each local transition, but long-horizon composition must emerge from repeated application of the learned state transition.

## Models

### Unitary

Each event has one learned Givens-rotation angle. The three angles begin at 0.1 radians.

### Matched non-unitary control

Each event has one learned unconstrained mixer scalar using the same adjacent pair topology.

Both paths receive:

- three trainable scalars;
- the same 12 training examples;
- the same central-difference gradient estimator;
- learning rate 0.15;
- 100 optimization steps;
- the same held-out sequences.

## Held-out composition

Evaluation contains 96 sequences:

- lengths 4, 8, 16, 32, 64, and 128;
- four starting states;
- four deterministic sequence seeds per length.

Targets are generated by the discrete swap state machine, not by either neural path.

## Pass conditions

For the unitary path:

- initial one-step train accuracy = 0.5;
- final one-step train accuracy = 1.0;
- held-out long-sequence accuracy = 1.0;
- final one-step loss <= 1e-4;
- each learned angle is within 1e-2 radians of pi/2;
- maximum norm drift <= 1e-12;
- maximum full-sequence forward/inverse round-trip error <= 1e-11;
- training loss is monotonic at recorded checkpoints;
- complete output is deterministic.

For the matched control:

- initial one-step train accuracy = 0.5;
- final one-step train accuracy = 1.0;
- long-sequence accuracy, loss, and norm drift are measured and must remain finite;
- it is not required to fail.

The full existing Wingless regression must remain green after advisory ICE rebuild.

## Interpretation boundary

A pass would show that the current unitary substrate can learn local transition operators from one-step examples and compose them correctly over sequences two orders of magnitude longer than anything seen in training, while preserving latent norm and reversibility.

That is evidence for a small sequential memory/composition primitive. It is not yet language reasoning.

A positive UP-4 permits UP-5: train a read/write memory task in which new facts overwrite or condition earlier facts and the final query requires retrieving the correct relation after intervening distractor events.
