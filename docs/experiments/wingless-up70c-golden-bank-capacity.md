# Wingless UP-70C — golden-tag bank-capacity extension

Status: preregistered scientific state-capacity experiment.

Scientific parent: sealed UP-69C Windows evidence `7c59d784b7a9cca434cd0e9787177ffa9a1ebb44`.

## Question

UP-69C remained depth-invariant through 4096 reversible transport steps, while boundary outcomes remained schedule-sensitive. With transport depth no longer the leading observed limitation, UP-70C asks how far the fixed 16-dimensional state can scale in multiplexed bank count under the existing golden-rotation tag family.

## Frozen design

Unchanged:

- state dimension 16;
- 256 deterministic scenarios;
- four entities per bank;
- golden-rotation phase tags generated by the existing `up57cGoldenTags`;
- coherence decoder and magnitude control;
- reversible transport depth 64;
- value-accuracy gate 0.99;
- exact-scenario gate 0.95.

Untouched deterministic schedule bases:

- 111M;
- 112M.

Bank counts:

- 6;
- 7;
- 8;
- 10.

Memory-noise levels:

- 0;
- 0.004;
- 0.008.

No tag optimization, state-dimension increase, decoder change, threshold change, adaptive stopping, bank selection, promotion, or activation is permitted.

## Interpretation

A bank-count boundary, noise-dependent collapse, schedule sensitivity, or continued success are all valid scientific results. This experiment does not authorize a larger state or select a bank count for production.
