# Wingless UP-169B — margin-rank class calibration

Status: preregistered scientific lexical-stability calibration experiment.

Scientific parent: sealed UP-168B.

## Question

UP-167B confined REPORT crossings to ranks 1..4 of 120. UP-168B generalized low-margin vulnerability to STORE/OBSERVE, but their tail extended to rank 10. Do these fixed class-conditional rank bands transfer to a different rehearsal-subject phase without fitting on its outcomes?

## Frozen preregistered bands

Derived only from accepted parent evidence:
- REPORT vulnerable band: ranks 1..4.
- STORE vulnerable band: ranks 1..10.
- OBSERVE vulnerable band: ranks 1..10.

Comparator:
- one universal rank-1..4 band for all classes.

No bands are changed after this experiment.

## Disjoint phase context

Parent diagnostics used old-rehearsal item assignment for terminal epoch 15.

This experiment reconstructs the same post-interference design with old-rehearsal subject assignment for terminal epoch 16:
- same six new-family subjects;
- same matched subject pairs;
- same 20 new-family prefix updates;
- same 3 pre-REPORT old updates, but epoch-16 old-subject assignment;
- same target-subject REPORT interference block;
- STORE→OBSERVE and OBSERVE→STORE path states built from epoch-16 old items.

## Independent probes

From fresh clones of each path state, independently probe all 15 epoch-16 old surfaces:
- STORE indices 0..4;
- OBSERVE indices 5..9;
- REPORT indices 10..14.

Rank all 120 old evaluation examples by absolute pre-step probability margin before each probe.

## Measurements

Per class:
- number of probe states;
- total crossings;
- maximum crossing rank;
- crossing coverage by the preregistered class band;
- crossing coverage by universal rank-4 comparator;
- total flagged example-slots under each band;
- crossing density among flagged slots.

## Interpretation

High class-band coverage under the disjoint epoch-16 phase supports rank-normalized class calibration. Loss of coverage defines the calibration boundary. Comparator performance quantifies why one universal band is or is not sufficient.

No maintenance action is triggered.

## Bounds

Diagnostic only. No fitted threshold, no adaptive band, no retained diagnostic update, no extra training, no memory/architecture change, no result-informed retry, no live activation, no production authority.
