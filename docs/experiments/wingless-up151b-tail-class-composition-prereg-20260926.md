# Wingless UP-151B — terminal-tail class-composition crossover

Status: preregistered scientific lexical-sequencing mechanism experiment.

Scientific parent: sealed UP-150B fffb8ea47a2cd58cf40c8eebb63b226cdadaa015.

## Question

UP-149B and UP-150B established that terminal shifts 0/12 are damaging and 6/18 are protective from the same 15-epoch state. UP-150B also reveals the remaining confound: both damaging tails contain four REPORT examples, while both protective tails contain two STORE plus two OBSERVE examples, and each pattern occurs for both Mia and Noah. Is post-anchor class composition itself the causal mechanism?

## Frozen common prefix

Reconstruct the exact accepted 15-epoch prefix:
- epochs 1–5: shift 0;
- epochs 6–10: shift 6;
- epochs 11–15: shift 12.

All arms start from the identical resulting gate.

## Frozen terminal design

For epochs 16–20 every arm:
- uses all 24 new-family examples exactly once per epoch;
- places 20 examples before the old anchor;
- executes the unchanged 15-update old anchor;
- places exactly four preregistered examples after the anchor;
- learning rate remains 0.08;
- no extra updates.

Subjects crossed independently:
- Mia;
- Noah.

Tail compositions, fixed before execution:

1. report_all
   - relays, announces, cites, summarizes.

2. store_all
   - lodges, stashes, caches, files.

3. observe_all
   - scans, checks, views, monitors.

4. mixed_seen
   - caches, files, scans, checks.
   - exact STORE+OBSERVE composition already observed in protective UP-149B tails.

5. mixed_alternate
   - lodges, stashes, views, monitors.
   - disjoint STORE+OBSERVE surface set.

This yields 10 subject × composition arms.

## Measurements

For each arm:
- common-prefix old retention;
- terminal mean prefix damage;
- terminal mean anchor recovery;
- terminal mean tail damage;
- terminal mean net epoch change;
- final old held-out/unseen retention;
- final mean old retention;
- final primary/secondary new-family accuracy;
- final mean new-family accuracy.

## Interpretation

If class composition dominates, the same composition should produce similar directional effects for Mia and Noah, and the alternate STORE+OBSERVE mixture should behave like the previously protective mixture despite using different verbs. If results instead depend strongly on individual verbs or subjects, the causal mechanism is more specific than class composition.

No arm is selected after observation and no numeric success threshold is introduced.

## Bounds

No adaptive tail choice, no extra updates, no new memory, no projector recomputation, no architecture change, no result-informed retry, no live activation, no production authority.
