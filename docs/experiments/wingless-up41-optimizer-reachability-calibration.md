# Wingless UP-41: direct optimizer reachability calibration

Status: preregistered calibration branch only; not activated, promoted, or connected to ckb-plane.

Parent research result: UP-40 qualified scientific negative sealed at `3df8ca932b974e7e12f103820550ad107dd71b91`.

Independent target provenance: UP-35 qualified positive sealed at `09284aa70203adf8881be42f67084c49b338dabe`, where the task independently constructed capacity-18 groups `[0,1,2,5]`, `[3]`, `[4]` and achieved perfect true held-out/mutable/final/relation performance.

## Question

UP-38 through UP-40 repeatedly improved their smooth objectives while direct optimization remained at capacity 6.

UP-41 asks a narrower mechanistic question:

**Can the frozen 12-step direct optimizer reach the fusion basin of a symmetry geometry already known, independently, to be useful—and if it cannot, which mechanism is responsible: sequential directional estimation, the 12-step update horizon, or irreversible sticky snapping?**

This is an optimizer calibration, not architecture selection.

## No task-selection authority

UP-41 uses:

- no task labels;
- no training tables;
- no validation tables;
- no held-out tables;
- no observer fitting;
- no architecture selection for future use.

The UP-35 target is an externally fixed calibration target that predates UP-38/39/40. No UP-41 arm is permitted to become a selected Wingless architecture.

## Fixed target

Target groups:

`[0,1,2,5]`, `[3]`, `[4]`

Target capacity:

`18`

Target offsets are generated by the existing `offsetsForSymmetryGroups` function under the same constraints:

- zero mean;
- RMS 0.05.

The calibration objective is cosine similarity between the current six-offset vector and this fixed target vector.

Cosine is bounded and scale-free; no post-result objective scaling is introduced.

## Frozen optimizer mechanics

All arms use:

- the same singleton initialization;
- zero mean;
- RMS 0.05;
- 12 update steps;
- perturbation 0.002 where finite differences are used;
- learning rate 0.002;
- maximum coordinate update 0.004;
- existing exact-fusion tolerance 0.0025 where sticky projection is enabled.

## Four diagnostic arms

### A — sequential + sticky

This is the current UP-38/39/40 optimization mechanic:

- one deterministic projected central-difference direction per step;
- irreversible exact fusion when group centroids enter the 0.0025 boundary.

### B — sequential + no sticky

Same directional estimator and update limits, but no irreversible fusion.

This isolates whether sticky projection is distorting an otherwise useful path.

### C — analytic cosine reference + sticky

Uses the exact analytic gradient of the calibration cosine objective while retaining the same learning rate, coordinate clamp, normalization, 12-step horizon, and sticky projection.

This is a reference, not a proposed production optimizer.

### D — analytic cosine reference + no sticky

Uses the exact analytic gradient with no irreversible projection.

This is the clean upper-reference arm for what the existing 12-step update budget can reach when gradient estimation and snapping are removed as confounds.

## Measurements

For every arm UP-41 records:

- initial, best, and final target cosine;
- all 12 offset trajectories;
- maximum spread inside the target fusion group;
- whether the target fusion basin is ever entered;
- whether the exact target grouping ever forms in sticky arms;
- whether any sticky fusion crosses target-group boundaries.

The **target fusion basin** uses the already-frozen exact-fusion tolerance: all members that should fuse must lie within 0.0025, while members belonging to different target groups must remain outside 0.0025.

No new numerical success threshold is invented.

## Frozen interpretation

The interpretation is based on exact mechanism comparisons:

- If the analytic no-sticky reference does **not** enter the target fusion basin within 12 steps, the frozen update horizon/step geometry is insufficient even with an exact gradient.
- If a sticky arm fuses members that belong to different target groups, irreversible snapping is directly demonstrated to be capable of locking a wrong structural decision.
- If analytic no-sticky achieves a higher best target cosine than sequential no-sticky, sequential one-direction estimation is a reachability limitation; the magnitude is reported exactly rather than thresholded after the result.
- If the current sequential+sticky arm reaches the exact target grouping, the existing optimizer is demonstrably capable of reaching a known-good symmetry and the task objective remains the primary suspect.

UP-41 does not alter any task gate from UP-40 because it does not evaluate task capability.

## Plain speak

We already know one useful symmetry pattern from UP-35.

Instead of asking the optimizer to discover anything new, UP-41 gives it a map and asks a simpler question: **can you physically get there with the steering system you currently have?**

Then it removes one steering limitation at a time.

If even the perfect-gradient reference cannot get into the fusion neighborhood in 12 moves, the problem is the travel budget. If the sticky mechanism locks the wrong coordinates together, that mechanism is unsafe for discovery. If the perfect gradient travels much farther than the one-direction estimator, the gradient estimator itself is leaving useful motion on the table.

That tells us what to repair next without changing the scientific target or hand-selecting a new architecture.
