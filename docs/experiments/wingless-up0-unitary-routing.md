# Wingless UP-0: unitary interference routing

Status: Windows-qualified research primitive; not activated, promoted, or connected to ckb-plane.

Baseline source: `3196880e54f89f2f55509ccf06ce627409c29bd4` (Stage 3.7 Windows acceptance seal).

## Question

Can a small complex-valued, norm-preserving propagator convert relative phase information into a deterministic routing signal that direct magnitude-only measurement cannot distinguish?

This is intentionally narrower than claiming language reasoning, quantum advantage, or frontier-model performance. UP-0 is a primitive check that the proposed computational mechanism is real, deterministic, reversible, and testable inside Wingless.

## Construction

`unitary.Propagate` applies bounded two-coordinate complex Givens rotations. Each local step is unitary and has a programmatically constructed inverse. UP-0 uses the special case generated by a Pauli-Y-like coupling at theta = pi/4.

Four normalized two-coordinate states are evaluated:

- two coordinates in phase;
- two coordinates in opposed phase;
- both states multiplied by the same global phase i.

Before propagation, each case has the same per-coordinate magnitude probabilities, so direct magnitude measurement cannot distinguish the two route classes. After propagation, constructive/destructive interference maps the relative-phase classes onto different basis coordinates.

## Pass conditions

- baseline magnitude routing accuracy is exactly 0.5;
- propagator routing accuracy is exactly 1.0;
- maximum norm drift is <= 1e-12;
- maximum propagate/invert round-trip error is <= 1e-12;
- invalid couplings fail closed;
- repeated probe output is deterministic;
- existing repository tests remain green after rebuilding advisory ICE.

## Authority boundary

UP-0 is an isolated mathematical research primitive.

It does not:

- register an inference backend;
- invoke a language model;
- activate the Wingless worker or plane listener;
- own queue, retry, workspace, acceptance, or promotion authority;
- execute model-selected tools;
- mutate ckb-plane, CKB, accepted refs, broker state, credentials, or production state.

A positive UP-0 result authorizes only the next research question: whether a trainable propagator can learn a bounded routing task under a matched classical baseline.
