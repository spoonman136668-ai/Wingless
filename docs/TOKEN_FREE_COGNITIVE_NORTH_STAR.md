# Wingless — token-free cognitive North Star (architecture clarification)

**Decision:** the operator requires all three independent target research architectures—Wingless, Yggdrasil and TTT-Hybrid-Lab—to be **strictly token-free**. This clarifies the Wingless standing North Star; it does not change or reclassify existing experiments.

## Binding requirements for future Wingless native candidates

- Target cognition must not contain a language tokenizer or token vocabulary, token IDs, subword/BPE segmentation, token-indexed working/long-term memory, next-token cross-entropy objective or autoregressive token decoding. This includes hidden/tokenizer-backed modules disguised behind a continuous adapter.
- Learn native representations from observation streams, physical/causal interactions and action consequences; maintain persistent native state, compositional/causal reasoning, unfamiliar-world transfer, cold retention and continued adaptation.
- Continue preserving the separate **non-transformer** requirement for Wingless. Do not substitute Yggdrasil's cellular substrate or Hybrid's SSM/attention composition.
- External textual communication or binary transport is an I/O serialization boundary, not a license for tokenized cognition. Test the native system's source-to-action reasoning without a tokenized intermediary.
- Independently trained conventional token-based/transformer systems may remain **external controls only**; they do not supply or count as target cognition, even if distillation or teacher evaluation is used.
- Judge progress by preregistered real-world action/outcome learning, cold memory, interference, unfamiliar transfer, retained capability and whole-process compute/memory, with trained controls, negative tests and authentic provenance. No benchmark-only or wrapper-based acceptance.

**Current status:** This is a future acceptance constraint, *not a claim* that current Go workers or model experiments already achieve native general cognition.

**Noninterruption:** No accepted science, frozen hypotheses, seeds/splits, runners, F139/autonomy controller, queue, tool authority, model deployment, active PR or CKB-plane runtime is modified by this documentation clarification. Existing qualifying candidates continue under their documented protocols; new candidate source requires separate source-custody and full platform qualification.

Related project charters are independent. Shared cognitive outcome does not grant cross-project edit, execution, merge or scientific first-use authority.
