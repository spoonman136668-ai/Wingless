# Wingless research executor — Codex-free mode (October 16, 2026)

## Decision and scope

Subscription-backed Codex is **not an authorized unattended research executor**. The existing research-cycle and legacy continuation scripts must never start Codex, try a second Codex model, read a Codex home directory, or consume the user's Codex allowance.

GitHub remains available for automated source qualification, regression tests, checksum-backed evidence and read-only supervision. The scheduled launchers remain installed for deterministic watchdog checks and report `advanced=false` with reason `gpt-authored-research-required-no-unattended-model` when a new model-authored step is needed. These no-op records **are not scientific results** and must not refresh or fabricate the previous independently verified scientific state.

## GPT-driven research work

The GPT research author works through the connected GitHub repository directly, preparing a bounded hypothesis, a preregistration-first change, its independently testable implementation, and follow-up evidence. Qualification uses authentic GitHub-hosted tests and preserved exact source identities. Research results, including negatives, remain subject to the existing science and first-use gates.

The ChatGPT web conversation is not itself a GitHub Actions unattended model runtime. A continuous model-authored research loop requires a separately qualified, authorized executor. No existing Nvidia/OpenRouter credential, new API spend, local desktop application, Cloudflare integration or Codex fallback is silently enabled by this transition.

## Retained safety controls

- No mutations of production, accepted scientific refs, CKB-plane, KTRADE, credentials or owner/witness authority.
- Preserve frozen North Star identity, preregistration, no-post-result tuning and independent qualification.
- Work in Wingless only. Do not conflate research evidence with FORGE optimizer promotion.
- Never translate a watchdog success, a no-model-executor skip or a synthetic fixture into a new experiment outcome.
- If there is no independently authorized unattended GPT executor, **do not invoke any model**. Report this condition plainly rather than treating the old Codex dependency as working autonomy.

This removes the automated Codex cost path. It does **not yet** establish unattended model-driven scientific progress.
