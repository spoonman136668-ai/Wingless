# Wingless North-Star Experiment Gates

**Status:** Proposed overlay on the existing research program  
**Rule:** Existing experiment families remain valid. New experiments should tag the nearest North-Star gate in addition to their local lineage.

## G0 — Mechanism characterization

Question: can internal state, history, capacity pressure, routing, memory, and procedure dynamics be measured causally?

Advance when:
- mechanisms are reproducible;
- interventions distinguish competing explanations;
- dominant resource terms are measured;
- hidden oracle information is excluded.

## G1 — Prospective self-observation

Question: can Wingless identify degradation or impending failure **before** observable capability loss from allowed native state?

Required evidence:
- held-out trajectories;
- frozen predictor/gate;
- false-positive and false-negative accounting;
- lead-time measurement;
- calibration/ranking measurement as appropriate;
- no future-outcome leakage.

Failure to generalize blocks advancement.

## G2 — Bounded self-maintenance

Question: can a frozen bounded rule use the warning signal to prevent failure with positive net benefit?

Required controls:
- no-intervention;
- resource-matched random or sham intervention;
- fixed action budget;
- unnecessary-intervention count;
- caused/accelerated failure count;
- opportunity/resource cost.

Advance only when benefit persists on held-out conditions.

## G3 — Retain / revert

Question: can Wingless preserve beneficial cognitive change and reject or exactly revert harmful change?

Required evidence:
- immutable pre-change checkpoint;
- independent acceptance test;
- exact rollback or equivalent verified restoration;
- regression testing of prior capabilities;
- no self-authorization.

## G4 — Transfer

Question: does retained improvement help on related unseen tasks, states, pressures, or trajectories?

Required evidence:
- held-out family or distribution shift;
- matched resource budget;
- no task/answer identity leakage;
- collateral capability accounting.

## G5 — Repeated iterative refinement

Question: can multiple G1-G4 cycles accumulate useful capability or robustness without catastrophic overwrite or near-linear resource expansion?

Required evidence:
- at least several sequential cycles;
- retained-benefit ledger;
- prior-capability probes after every cycle;
- resource-growth accounting;
- beneficial-change rejection/rollback controls.

Only here may the phrase **iterative refinement** be used as a demonstrated system property.

## G6 — Functional LLM integration

Question: can Wingless provide persistent cognitive value around a strong, replaceable general-purpose LLM core?

Required evidence:
- stable model-adapter contract;
- at least two compatible model backends where practical;
- persistent procedures/memory survive model replacement or version change within declared limits;
- model cannot bypass authorization or write durable state directly;
- useful end-to-end tasks show measurable benefit beyond the LLM-only baseline.

## G7 — Guardrailed autonomy

Question: can the bounded refinement loop operate without constant human steering while remaining inside immutable authority, resource, containment, audit, and rollback boundaries?

Required evidence:
- no self-expansion of permissions/resources;
- independent verifier and authorization path;
- safe abstention/OOD behavior;
- externally enforceable stop;
- deterministic or statistically reproducible provenance;
- repeated retained improvements under held-out challenges.

Passing G7 still does not imply unrestricted recursive self-modification.

## Current position marker — 2026-09-27

Evidence presently places the active frontier around **G1/G2**, with meaningful mechanism, warning, gating, and counterfactual intervention results. G3-G7 are not yet demonstrated as closed system properties.

This marker is descriptive and should be updated only from repository evidence.
